## Related Work

### Seo et al. (NeurIPS 2025) — arXiv:2510.09008
Seo et al. propose a **visual grounding signal** derived from the attention weights of a pretrained vision‑language transformer. They extract a *spatial attention map* from the cross‑modal encoder and inject this map into the decoder as an auxiliary bias to steer token generation toward objects that are attended to in the image. The signal is injected **at every decoding step** into the decoder’s hidden state, effectively modulating the language model with a dynamic visual prior. UGAA differs because it does **not** modify the decoder internals; instead it applies a **constant NO‑bias** directly to the final yes/no logits, a training‑free, inference‑only perturbation that leverages the decoder’s intrinsic logit gap rather than explicit attention manipulation.

### AdaptVis (ICML 2025) — arXiv:2503.01773
AdaptVis introduces a **domain‑adaptive visual prompt** that aligns visual features with language tokens through a learned linear projection. The method targets the **VQA benchmark**, training the projection on a small subset of VQA data to improve answer consistency. The visual signal is injected **into the input embedding layer** of the language model, allowing the model to treat visual cues as part of its token vocabulary. UGAA differs because it requires **no additional training data or learned projection**; the constant bias operates purely at the output layer, making it applicable across any benchmark (including POPE and What’s Up) without retraining.

### VisFlow (AAAI 2026) — arXiv:2506.12609
VisFlow defines two novel signals: **Task‑Aware Interaction (TAI)** and **Hierarchical Attention Influence (HAI)**. TAI captures high‑level task relevance by computing the similarity between the task description and visual features, while HAI aggregates multi‑scale attention maps to form a hierarchical saliency cue. Both signals are derived from **pre‑trained vision encoders** and are fused into the language model via a **gating network** placed before the final classification head. UGAA differs in that it avoids any **gating network or hierarchical processing**; it simply offsets the NO logit, exploiting the decoder’s existing certainty signal, which is shown to be sufficient for hallucination reduction without extra architectural components.

UGAA differs because it is a **training‑free, inference‑time logit adjustment** that leverages the decoder’s inherent yes/no logit gap, whereas the above methods rely on **learned or dynamic visual signals** injected at various stages of the model (attention maps, embedding projections, or gating networks). This simplicity enables UGAA to be applied universally across benchmarks without additional data or model modifications.
